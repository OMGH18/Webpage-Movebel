# Illustrations des voyages

Dépose ici une image par voyage, nommée **exactement** comme l'identifiant
ci-dessous (`.webp`, `.jpg` ou `.png`). Dès qu'un fichier existe, il remplace
automatiquement le paysage SVG de secours, sans toucher au code.

| Fichier | Voyage |
|---|---|
| `lumiere` | Lumière, l'île imaginaire (gratuit, affiché en grand) |
| `inca-trail` | Chemin de l'Inca |
| `halloween-trail` | Sentier hanté (saisonnier) |
| `everest-bc` | Camp de base de l'Everest |
| `mont-blanc` | Tour du Mont-Blanc (sert aussi de fond à la section écologie) |
| `camino` | Chemin de Compostelle |
| `pole-nord` | Route du Pôle Nord (saisonnier) |
| `uk-lejog` | Land's End – John o' Groats |
| `paris-rome` | Paris – Rome |
| `tour-de-france` | Tour de France (aussi sur la carte du haut de page) |
| `route-66` | Route 66 |
| `usa-coast-to-coast` | Traversée des États-Unis |
| `silk-road` | Route de la soie |

## Format conseillé
- Paysage **16:9**, 1600 × 900 px minimum (Lumière est affiché plus grand).
- Sujet important **au centre** : l'image est recadrée selon l'endroit
  (carte 16:9, carré en haut de page, bandeau large).
- Pas de texte dans l'image. Les km et noms sont ajoutés par le site.
- Style identique pour les 13 (même palette, même lumière) pour un ensemble cohérent.
